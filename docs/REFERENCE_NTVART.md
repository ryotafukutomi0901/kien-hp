# デザインの手本: 日本テレビアート（2026-10-27）

CEO指示「このサイトをガチで参考にして模倣対象にしてほしい」（https://www.ntvart.co.jp/ ）。
手本の**型**（レイアウト・文字組み・色の使い方・動き）を、喜援の内容とロゴの色で組み直した。
**手本の画像・文章・ロゴ・コードは使っていない**（画像は喜援の仮画像、文言は旧サイトの原文、欧文の飾りは原文の意味から作った）。

値の正本は `styles/tokens.css`。この文書は「手本の何を、どう置き換えたか」の記録。

## 4. 守っている約束

- h1〜h3 の書体と太さは1つ（`Ubuntu → けいなんむぎまるJP` の1つの指定）。見出し・小見出し・本文の差は文字サイズだけ（2026-10-21 打ち合わせ、2026-10-28 CEO指示）。段差は `styles/tokens.css` の Typography: size のコメント
- 文字のコントラストはすべて AA 以上（`node scripts/audit.mjs` で全ページ×5幅を実測）
- 欧文の飾りは `aria-hidden`。見出しの読み上げは日本語
- 動きは `prefers-reduced-motion` で止まる。ヒーローの描画は画面外・タブが裏のときに止まる

## 5. 手本のヒーローの動き（2026-10-28 実測。CEO指示「ヒーローの動きの始まりから再現できるように」）

手本を GPU ありのブラウザで開き、読み込み完了の合図（`loaded`）を 0 秒として録画した。数値は手本の CSS・JS から読み、録画で確かめた。
録画とコマ送りの画像は手本の著作物なので、このリポジトリには置かない（作業用の一時フォルダだけ）。

| 時刻 | 何が起きるか | 長さ・緩急 |
|---|---|---|
| 0.0s | 白い読み込み画面が透けて消える | 1.0s、`cubic-bezier(.26,.16,.1,1)` |
| 0.0s | 中央から白い同心円（3重、不透明度 .2 / .4 / .8）が広がる | 2.0s、power3.inOut |
| 1.1s | 色の丸が中央から外へ飛び出す（トンネル） | 2.0s、power3.out |
| 1.75s | 写真カードが中央から飛んできて、傾いて浮かぶ | 3.0s、power3.out |
| 2.9s | 見出しが1文字ずつ下からせり上がる（下の「文字ごとの動き」） | 1文字 0.6s、0.05s ずつずらす |
| 2.9s + 1.0s | 日本語の副題が同じ動きで続く（見出しの最後の文字から 0.3s あけて） | 同上 |
| 5.0s | 右下のお知らせカードが右から 60px 滑り込む | 1.0s、戻りのある緩急 |

文字ごとの動き:

- 行ごとに `overflow: hidden` の箱で囲み、1文字ずつ `inline-block` にする。各文字は `translateY(50%)`・透明から始まる
- 合図で `translateY(0)`・不透明へ。位置は 0.6s `cubic-bezier(.175,.885,.32,1.275)`（少し行き過ぎて戻る）、透明度は 0.6s `cubic-bezier(.26,.16,.1,1)`
- 遅れは「通し番号 × 0.05s」。1行目と2行目は番号が続き、副題は番号を飛ばして間をあける
- 読み上げは見出し全体の `aria-label`。1文字ずつの箱は `aria-hidden`

読み込み画面（参考）: 白地の中央にロゴ（画面幅の30%）。ロゴの部品ごとに 2.5s の繰り返しで 30px 跳ね、部品ごとに 0.2s ずらす。
フォント・画像・WebGL の準備がそろうまで待つ。

### 喜援版（2026-10-28 実装。CEO指示「喜援版で入れて」）

手本のコードは使わず、上の順番・時間・緩急だけを借りて組んだ。読み込み画面は置かない。

| 時刻 | 喜援 |
|---|---|
| 0.0s | 全ページの背景の白い同心円が、中央の点から広がる |
| 1.1s | 背景の色の丸（まれにロゴのマーク）が、中央から外へ飛び出す |
| 1.75s | ヒーローの写真（後ろの色の面・バッジごと）が、画面の中央寄りから傾きを戻しながら飛んでくる |
| 2.9s | 「人を大切にする」「会社になる」が1文字ずつせり上がる。リード「富士市にて…」が続く |
| 4.6s | ボタン2つ |
| 5.0s | 右下の Instagram のカードが右から滑り込む |

- 合図は `lib/intro.ts`（`<html data-intro="wait|play">`）。時刻は `styles/tokens.css` の `--intro-*`
- 流すのはトップを直接開いたとき（再読み込みを含む）だけ。サイト内の移動でトップに戻ったとき・動きを減らす設定・トップ以外のページでは流さない
- 見出しは `aria-label` で文のまま読み上げる。リードは隠し文で読み、1文字ずつの箱は読み上げない
- 演出の前後の状態の保存と戻し方は [`REVERT_2026-10-28.md`](./REVERT_2026-10-28.md)

## 6. フッターの動き（2026-10-28。CEO指示「フッターとその下の Our SNS も手本に」「フッターは文字の大きさ・配置はそのまま、動きだけ」）

手本のフッターの動きは、すべてマウスを乗せたときのもの（スクロールに合わせた動きは無い）。手本の CSS から時間と緩急を読み、
喜援のフッターに同じ時間で組んだ（`components/layout/Footer.module.css`。手本のコードは使っていない）。

| 場所 | 手本 | 喜援 |
|---|---|---|
| サイトマップのリンク | 先頭の丸（淡いグレー＋黒い「›」）が 0.1s で黒＋白い「›」に。文字が 6px 右へ寄り、下線が左から引かれる（0.1s）。離すと文字と下線は 1s `cubic-bezier(.43,.05,.17,1)` で戻り、下線は右へ縮んで消える。丸の色は 1s `cubic-bezier(.26,.16,.1,1)` で戻る | 同じ時間・緩急。先頭の丸は喜援の枠線だけの丸のまま、乗せると黒く塗られる |
| プライバシーポリシー | ふだんから下線。乗せると下線が右へ消え（0.2s）、続けて新しい下線が左から引かれる（0.2s）。離すと一瞬で元へ | 同じ |
| Page Top | 淡いグレーのピルが 0.2s で黒地・白文字に | 0.2s でコーラルの地に（黒い面は使わない方針。文字はほぼ黒のままで 5.8:1）。それまでの矢印が上へ跳ねる動きはやめた |
| 所在地 | オフィスのカードに乗せると写真が 1.2倍になり、住所に下線が引かれる（カード全体が地図へのリンク） | 入れない。喜援の所在地はリンクではなく写真も無いので、下線を引くと押せそうに見えてしまう |
| スマホ | 見出しごとに開閉する（矢印が 0.4s で裏返る） | 入れない。喜援のスマホのフッターは開閉式ではなく、配置を変えない指示のため |
| Official SNS | 上下を線で挟んだ段の左に「Official SNS」＋Instagram、右にプライバシーポリシーと Page Top。コピーライトはその下の右端 | 同じ並び。Instagram の URL が未入手の間も仮のリンクで出す（ヒーローのカードと同じ扱い）。文字の大きさとアイコンは喜援のまま |

- マウスの無い端末（タッチ）では動かさない（`@media (hover: hover)`）。マウスのある端末では、キーボードで選んだとき（`:focus-visible`）も同じ動きになる
- 動きを減らす設定では `styles/base.css` が時間を 0 にする
- 入れる前の状態の保存と戻し方は [`REVERT_2026-10-28.md`](./REVERT_2026-10-28.md) の「フッターの動き」
