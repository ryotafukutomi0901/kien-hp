# 02 Hero

## 目的
最初の画面で「富士市の地域に根ざした介護事業者」だと伝え、想い（About）へ誘導する。主コピーが最も強い要素。

## 内容
`data/sections/hero.ts`（主コピー2行・リード3行・ボタン「私たちの想いを見る」・写真）

## デスクトップ（1440基準）
- 範囲: モック y62〜約470。写真の下端は白い波で切れ、左が高く右が低い（左端 y≈355 → 中央 y≈400 → 右端 y≈455）。高さは約680px
- 写真: 富士山が右寄り・山頂がやや上。街並みが下半分。左側（コピーの背後）は空が白っぽく霞む → 写真の上に左から白へのごく薄いフェードをCSSで重ね、文字の読みやすさを確保（グラデーションは霞の再現に限る）
- 主コピー: x78→129（コンテナ左端）、上端 y130→ヘッダー下から約110px。`--t-display`、Klee One 600、字間は広め（約0.16em）、2行、行送り約1.45、色 `--color-text`
- リード: 主コピーの下 約40px、3行、`--t-body`、500、字間0.12em前後、行送り約1.8
- ボタン: リードの下 約24px、`Button size="lg"`（約300×56）
- 葉っぱ（LeafDecoration）: 左上の角（`top-left`、約240px幅）、右上の角（`top-right`）、左端の中ほど〜下（`bottom-left` を小さく）、右下に大きな房（`bottom-right` と `top-right` を重ねる等。モックは黄色い花まじり）。右下の房は波の線をまたいでServicesの上端にかかる
- 波: SVGで作る（`preserveAspectRatio="none"`、塗りは `--color-bg-soft`）。直線や単純な円弧にしない

## タブレット（640〜1023）
- 高さ約560px。コピーはそのまま左、写真は `object-position` で富士山を右に残す。葉っぱは2/3程度に縮小

## モバイル（〜639）
- 写真を縦長に使い、富士山が右上〜中央に見えるよう `object-position` を調整。コピーは上、ボタンは下
- 白いフェードは左→右ではなく上→下（コピーの背後）に切り替えて可読性を守る
- 主コピー2行が1行あたり収まること（折り返さない）。リードは3行のまま
- 葉っぱは左上・右下の2か所だけ、小さく
- 波は振幅を小さく

## 合格条件
- 1440で主コピー・リード・ボタンの位置と大きさがモックと見比べて一致、波の形が左高右低
- 文字の背後のコントラスト: 本文色と背景（フェード後）で4.5:1以上（ピクセルを実測）
- 375で主コピーが折り返さず、横スクロールなし
- `next/image` の写真は `preload`（LCP）
