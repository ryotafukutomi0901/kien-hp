# 09 Footer

## 目的
会社情報とナビを再掲し、SNSとページ上部へ戻る導線を置く。

## 内容
`data/site.ts` の `company` `nav` `social`（このファイルは編集しない）

## デスクトップ
- 地 `--color-footer-bg`、高さ 133→約220
- 左上: 白いロゴ（`Logo tone="light"`）。モックはヘッダーのロゴの約0.9倍。太陽マークは白（`Logo.module.css` の `.light` のルールで白くする。`.light` 以外は変えない）
- ロゴの下: 住所「〒417-0061 静岡県富士市富士見台251番地の1」（実装時の実測で `--t-note`・白・500に変更）
- 右上: ナビ7項目を横一列（`--ui-nav`、白）。ロゴの中央と高さを揃える
- 右下: Instagram・Facebook（白、見た目約32px、タップ領域44px）。そのさらに右に「ページ上部へ戻る」丸ボタン（直径44、淡いグレー地に紺の矢印。コンテンツ右端から最大60pxはみ出す）
- 最下部中央: コピーライト（`--ui-caption`）

## タブレット（640〜1023）
- 2段: 上段にロゴ＋住所、下段にナビ（折り返し可、2〜4列）。SNSと戻るボタンは右下

## モバイル（〜639）
- 縦積み: ロゴ→住所→ナビ（2列グリッド、各行44px以上）→SNS→コピーライト。戻るボタンは右下

## 合格条件
- 1440でロゴ・ナビ・SNS・戻るボタンの位置がモックと一致、ロゴが白
- 文字のコントラスト4.5:1（フッター地で実測）、SNSのリンクに読み上げ名
- 375で横スクロールなし
