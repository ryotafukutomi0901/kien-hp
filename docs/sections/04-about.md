# 04 About

## 目的
事業所の使命を短く伝え、事業所・会社案内へ送る。富士の風景で地域性を印象づける。

## 内容
`data/sections/about.ts`（見出し・本文3行・ボタン・背景写真・楕円写真）

## デスクトップ
- 範囲: モック y900〜1118 → 高さ約360。全幅の写真背景
- 背景: 富士山の風景を大きくぼかし（CSS `filter: blur()`、拡大して端の白抜けを防ぐ）、左半分は白く霞ませる（左から右へ白→透明のフェード）。右端に葉っぱ（`single` / `top-right`）、左上に葉っぱ（`top-left` 小）
- 見出し: `SectionTitle variant="brush"`、x73→コンテナ左端
- 本文: 3行、`--t-body`、字間0.12em前後、行送り約1.9
- ボタン: `Button size="lg"`「事業所・会社案内」
- 楕円写真: 右側、365×202 → 約605×335、白い太枠（約8px、`--color-bg`）と薄い影。写真は富士山の山頂が楕円の上1/3に来るよう `position` 調整。楕円は `border-radius: 50%`（`clip-path` 可）
- テキスト列と楕円は縦中央揃え

## タブレット（640〜1023）
- 2列のまま楕円を縮小（幅45%程度）。本文の改行は維持

## モバイル（〜639）
- 1列: 見出し→本文→ボタン→楕円写真（幅いっぱい・比率維持）。背景のフェードは全体に白をかけて文字を読ませる
- 葉っぱは右上1か所に減らす

## 合格条件
- 1440で楕円の大きさ・白枠・位置、テキストの位置がモックと一致
- 背景がぼけて見え、テキストが4.5:1以上で読める（実測）
- 375で横スクロールなし
