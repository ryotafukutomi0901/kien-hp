# kien-hp デザイン仕様（DESIGN.md）

参考モック（`reference/mock.png`）を Next.js で再構築するためのデザインシステム。
**トークンの正本は `styles/tokens.css`**。この文書は「なぜその値か」と「セクションごとの実測値」を残す。
数値を変えるときは tokens.css を直し、この文書の該当行も直す。

## 0. 前提

- 参考モックは幅869px。デスクトップ1440px相当に換算するときは **×1.657** を使う
- 素材シート `reference/asset-sheet.png` から切り出した仮画像を `public/images/` に置いている
  （`scripts/extract-placeholders.py`）。写真は200px前後しかなく、本番素材が届いたら同名で差し替える
- 規程: `handbook/02_quality/web_design_standard.md`（余白スケールの単一化・文字サイズ3トークン・UIラベル共通化）

## 1. デザインブリーフ（ui-ux-pro-max の出力）

| 項目 | 決定 |
|---|---|
| 業界カテゴリ | 医療・ヘルスケア寄りの地域サービス（訪問介護）。清潔感・安心感・読みやすさを最優先。読者には高齢のご家族も含む |
| UIスタイル | 水彩の葉っぱと富士山の写真で温かさを出すナチュラル系 × カード区画型。ガラス・グラデーション・3Dは使わない |
| 視線導線 | ヒーローは左コピー／右に富士山のZ型。以降は左揃えの見出し→カード群の繰り返しだが、セクションごとに形を変える（2×2カード／楕円写真／4列サムネイル／行リスト／横長カード2枚／帯CTA） |
| 主CTA | 「お問い合わせ」（ヘッダー常設＋最終CTA）。各セクションのボタンは副CTA扱いだが、モックどおりすべてオレンジのピル型 |
| カラー | Primary=オレンジ、Neutral=紺系の文字＋オフホワイト地、トーン4色はサービスの識別用（意味を色だけに頼らずアイコンと見出しを併用） |

| 避けるアンチパターン | 紫系グラデーション、根拠のない社会的証明、意味のない浮遊アニメーション、カルーセルへの情報押し込み、デスクトップの単純縮小 |

## 3. タイポグラフィ

サイズは区分ごとに個別値（規程第5条2項）。単位rem。

| トークン | mobile | tablet ≥640 | desktop ≥1024 | wide ≥1280 | 用途 |
|---|---|---|---|---|---|
| `--t-display` | 2.25 | 2.75 | 3.5 | 4 | ヒーローの主コピーのみ（規程第6条の例外。モックで見出しの約1.8倍） |
| `--t-heading` | 1.625 | 1.75 | 2 | 2.25 | セクション見出し |
| `--t-body` | 1.0625 | 1.125 | 1.25 | 1.25 | リード文・カード見出し・About本文 |
| `--t-note` | 0.9375 | 0.9375 | 1 | 1 | 説明文・本文の既定 |

UIラベル（役割ごとに1種類、規程第3条）: `--ui-nav` 0.875 / `--ui-button` 0.9375 / `--ui-button-sm` 0.875 / `--ui-meta` 0.875（日付・小リンク） / `--ui-caption` 0.75。
行間 `--lh-heading` 1.5・`--lh-body` 1.9。字間 見出し0.12em・本文0.06em・UI0.08em（モックは字間が広い）。

## 4. 余白・レイアウト

- 余白スケール: `--space-1`〜`--space-12` = 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 80 / 96 / 128px。**これ以外の値で余白を作らない**
- コンテンツ幅: `--container-max` 1200px（モックのサービスカード群 723px×1.657）。枠は必ず `components/common/Container` を使う
- 左右余白 `--container-pad`: 24 / 40px（≥640）
- セクション上下 `--section-pad-block`: 64 / 80（≥640） / 96px（≥1024）
- ヘッダー高 `--header-height`: 64 / 96px（≥1024）
- ブレークポイント: 640 / 1024 / 1280px（モバイルファースト。CSS変数はメディアクエリに使えないため各CSSに数値で書く）

## 5. 形・コンポーネント

| 部品 | 仕様 |
|---|---|
| `Button` | ピル型（`--radius-pill`）、末尾に矢印。`variant` primary / outline、`size` lg 56px（ヒーロー・About）/ md 48px（ヘッダー・最終CTA）/ sm 40px（カード内・一覧） |
| `ArrowLink` | 「詳しく見る →」等の小リンク。`tone` で色、高さ44px |
| `SectionTitle` | `variant` brush（手書き見出し＋緑の筆線）/ mark（左上オレンジ三角＋ゴシック太字） |
| `LeafDecoration` | 葉っぱ6種。位置は呼び出し側のclassNameで指定、aria-hidden |
| `Logo` | 太陽マーク画像＋社名テキスト。`tone` dark / light |
| `Icon` | 線画SVG。円形の地はセクション側で付ける |
| 角丸 | `--radius-sm` 4 / `--radius-md` 8（カード） / `--radius-lg` 16 / `--radius-pill` |
| 影 | `--shadow-card`（ごく薄い）、`--shadow-button` |
