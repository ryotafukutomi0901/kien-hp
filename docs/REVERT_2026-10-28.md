## ボタンの動き（2026-10-29 に追加）

CEO指示「お問い合わせとヒーローのボタンアニメーション変えたじゃん？他のボタンも変えてほしいんだけど、既に使用しているものは避けて他のアニメーションを使って」。

| ボタン | マウスを乗せたときの動き |

| コーラルのボタン（お問い合わせ以外） | 文字が上へ抜けて下から同じ文字が入り、白い丸の矢印が右へ抜けて左から戻る |

| 白いボタン | コーラルの線が縁を一周して描かれ、少し浮く |
| ほかの事業のピル | 目印の顔が首をかしげる |
| ページ内リンクの小さなピル（採用の目次・ニュースの年） | ぷるんと弾む |
| 「〜について →」の文字リンク・事業カード裏の「詳しく見る」 | 矢印の軸が右へ伸びる |
| 電話のボタン（お問い合わせ・採用） | 電話の絵・「TEL」が鳴るように揺れる |
