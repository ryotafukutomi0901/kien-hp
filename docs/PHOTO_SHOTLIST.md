# 撮影カット一覧（2026-10-27）

2026-10-21 引き継ぎ 10「撮影した写真をサイトに活用するため、必要なカットを整理する」への回答。
**使う場所ごとに、何を撮り、どんな枠で切り出されるか**をまとめた。撮影前の打ち合わせと、届いた写真の振り分けに使う。

写真は仮画像（画像生成AIの出力）を使っている。差し替えは **同じファイル名で `public/images/` に置くだけ**（`CLAUDE.md`）。
位置の微調整は `data/sections/*.ts` の `image.position`（`object-position`）で行う。

## 0. 撮影の共通ルール

- **縮小しない元の写真**をもらう（スマホで撮ったままでよい）。仮画像の画質が悪い最大の原因は小ささ（[`IMAGE_QUALITY.md`](./IMAGE_QUALITY.md)）
- **横位置と縦位置の両方**を撮る。PCは横長、スマホは縦長に近い枠で切り出す場所がある
- **掲載できる素材だけ**を使う。利用者様が写る写真は、ご本人・ご家族の**書面での同意**が必要（`CLIENT_CHECKLIST.md` #12）。同意が取れないときは、手元・後ろ姿・物だけの構図にする
- 顔は枠の**中央寄り**に置く（上下・左右の端に置くと、PC・スマホのどちらかで切れる）。被写体の周りに、各辺 10〜15% の余白を空けて撮る
- 暗い・逆光・手ぶれの写真は避ける。窓際の自然光で、カメラを少し引いて撮る

## 2. 撮影の優先順位

1. **ヒーロー（#1）と採用情報（#7）**: 見出しと背景の不一致（01）と、サイトの目的（採用）に直結する
2. 事業内容の3枚（#3〜5）と経営理念（#2）
3. 会社行事（#6）は、これまでの写真に加えて新しい行事の分
4. その他（#8〜11）

## 3. 届いたあとの作業

1. `reference/generated-originals/` に原本を置く（実行時には使わない）
2. `python3 scripts/optimize-images.py` で `public/images/` 用に最適化（幅・容量・形式）。スクリプトの対象ファイル名に合わせる
3. 各 `data/sections/*.ts` の `alt` を、写真の内容を表す文に直す（人物の特定につながる情報は書かない）
4. `node scripts/shot.mjs` で PC（1440）・タブレット（768）・スマホ（375・320）を撮り、**顔や重要部分が切れていないか**を見る。切れる場合は `image.position` を調整する
5. 仮画像（`IMAGE_QUALITY.md` の表）を本番素材で置き換えたら、そのファイルを削除する
