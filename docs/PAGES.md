# 下層ページの定義書

トップ以外のページ。**内容の正本は [`CONTENT_SOURCE.md`](./CONTENT_SOURCE.md)**（原文は `reference/old-site-text/`）。ここは「どのページに何を、どの順で置くか」だけを決める。

## 全ページ共通のルール

- **旧サイトに無い事実は書かない。** 数字・固有名詞・サービス内容は原文のまま。言い回しの要約・整理は可だが、意味を足さない・変えない。「CONTENT_SOURCE.md 9章 食い違い・要確認」の項目は、表の「新サイトでの暫定扱い」の列に従う
- **社内向けのメモ（要確認・食い違い・未実装・仮）は、公開ページに書かない。** 出すべきでない情報は報告に書いて統括に返す
- 営業電話お断りの注記（「※営業のお電話はご遠慮ください。」）は、会社に連絡する導線のあるページ（お問い合わせ・採用情報・事業所）に置く
- 構成: `PageIntro`（h1・導入文）→ `PageSection`（h2、ページ内リンク用の `id` 付き）の並び。地色は `tone="plain"` と `"soft"` を交互にする
- 共通部品は `components/page/`（PageSection・DefinitionList・Faq・Timeline・Notice）と `components/common/`（Button・ArrowLink・Container・SectionTitle ほか）。**これらは編集しない**。足りないものは各ページのフォルダに最小限で作り、共通化したいものは報告で統括に返す
- 色・余白・文字サイズは `styles/tokens.css` の変数だけ（`handbook/02_quality/web_design_standard.md`）。本文は `--t-note`、リードや強調は `--t-body`、節見出しは `SectionTitle`
- 写真は使わない（旧サイトの写真は未取得で、仮画像は内容と関係がない）。装飾が必要なら `LeafDecoration` だけ
- **家事支援の料金表（`components/page/PriceGuide.tsx`）は、家事支援事業のページ以外の全ページに置く**（2026-10-21 引き継ぎ 05）。置き場所は各ページの最後（お問い合わせの帯・フッターの直前）。プライバシー・404には置かない。表の値は `data/pages/services.ts` の `homeHelp.fee` だけが出どころ
- 電話番号は `tel:` リンク（`0545-32-7860` → `tel:0545327860`）にし、タップ領域を `--tap-min` 以上にする
- 各ページに `export const metadata`（title と description。description は原文から）
- 追加ライブラリ禁止。`npm run build` は実行しない（統括が行う）。git commit しない

## ファイルの置き方

| 種別 | 置き場所 |
|---|---|
| ページ | `app/<route>/page.tsx` |
| ページ専用の部品 | `components/pages/<名前>/` |
| ページの文言（原文の転記） | `data/pages/<名前>.ts`（型はそのファイル内に定義してよい） |
| 会社行事・ニュースの記事 | `data/records/events.ts` `data/records/news.ts`（読み取りのみ。編集しない） |
